# 三模搜索框架设计

> 日期：2026-09-16 | 范围：5 张两模验收失败的图（4/8(1)/9/10/11 奇点）
> 状态：设计定稿，待实现

---

## 一、问题定义与目标

两模验收暴露的系统性失败：5 张图的实验暗点数 4~11 个，而两模解最多只能产生 1~5 个暗点。**两模的表达能力不足以重建这些结构**。本框架将搜索空间扩展到**三个模式**：

目标：对每张失败图，找到"三模解"——使求出的三模理论图在
1. **相关系数**（PCC）上不显著低于两模解；
2. **结构验收**（暗点数量与位置）上**通过**（这是本次升级的核心目的）。

---

## 二、物理模型与数学

### 2.1 场模型

```
E = a1·F1 + a2·F2·e^{iφ2} + a3·F3·e^{iφ3}      (φ1 ≡ 0，全局相位规范)
a1² + a2² + a3² = 1                              (能量自动归一化)
```

模式 F ∈ 联合基底（66 HG + 65 LG = 131 个，阶数 ≤ 10）。

### 2.2 9 基场分解（解析扫描的关键）

三模光强可展开为 **9 个实基场的线性组合**：

```
I = c·G,   G = [ B1, B2, B3, C12, S12, C13, S13, C23, S23 ]

B_k  = |F_k|²                  （3 个自强度项）
C_jk = Re[F_j·F_k*],  S_jk = Im[F_j·F_k*]   （6 个交叉项）

系数：
c_B1 = a1²,  c_B2 = a2²,  c_B3 = a3²
c_C12 = 2a1a2·cosφ2,   c_S12 = 2a1a2·sinφ2
c_C13 = 2a1a3·cosφ3,   c_S13 = 2a1a3·sinφ3
c_C23 = 2a2a3·cos(φ2-φ3),  c_S23 = -2a2a3·sin(φ2-φ3)
```

### 2.3 相关系数的二次型

Pearson 相关 = c 的显式函数：

```
corr(c) = [ c·E − (c·m)·μ_e ] / sqrt( [ cᵀG c − (c·m)² ] · σ_e² )

m_i = <G_i>,        E_i = <G_i · I_e>,        G_ij = <G_i·G_j>
μ_e = <I_e>,        σ_e² = var(I_e)
```

每个三元组预计算 **9 + 9 + 45 = 63 个标量统计量**后，整个参数网格上的
相关系数评估变成纯向量运算（GPU 秒级）。

### 2.4 参数空间与冗余

| 维度 | 说明 | 网格（粗筛 / 精筛） |
|---|---|---|
| 模式三元组 | 无序三元组 C(131,3) = **366,145** | 全空间 |
| 能量 (a1²,a2²,a3²) | 2 自由度（归一化后） | 45 点（步长 1/8）/ 231 点（步长 1/20） |
| 相位 (φ2, φ3) | 2 × [0, 2π) | 12×12（30°）/ 24×24（15°） |

对称性处理：
- 模式置换：只枚举无序三元组 (i<j<k)；
- 共轭镜像 (l→-l)：等价表示，报告时合并标注；
- 退化解（a3→0 时退化为两模）：允许存在，用于与两模结果对接。

## 三、计算架构（三层筛选）

### Layer 1：全空间粗筛

- **降采样**：实验图与模式场降采样到 **64×64**（统计量与网格评估均在降采样域，成本 ÷12）；
- 366,145 三元组 × (45 能量 × 144 相位 = 6480 网格点)，评估 corr，每个三元组保留最大值；
- **产出**：全局 top-200 三元组（附粗参数）。

**计算量估算**：

| 项目 | 规模 | 估计 |
|---|---|---|
| 统计量（63 内积/三元组，64² 域） | 366k × 63 × 4096 | ≈ 1.9×10¹¹ flops |
| 网格评估（二次型） | 366k × 6480 × ~60 | ≈ 1.4×10¹¹ flops |
| 合计 | ≈ 3.3×10¹¹ flops | GPU 上 **约 3~10 分钟/图** |

批处理：256 三元组/批，峰值显存约 100 MB。

### Layer 2：精化

- 对 top-200 三元组，在**原分辨率 224²** 上重算统计量；
- 细网格扫描（231 × 576）后做**坐标下降**（能量 u、v → φ2 → φ3 循环收敛，步长逐轮减半）；
- 产出：每图 top-20 精化解。

### Layer 3：结构验收

沿用已验证的暗点检测器（与两模验收完全同一套）：

- 实验图暗点为基准；
- 对 top-20 三模解逐一渲染复场 → 检测暗点 → 数量（±1容差）+ 最近邻位置（< 12 px）；
- 汇总表：相关系数 × 结构验收双重排序，**优先输出"高相关 + 结构通过"的解**。

## 五、验证方案（实现后立即执行）

1. **合成自测**：构造已知三模图（包含两模无法覆盖的"多暗点"结构，如三模涡旋晶格），验证：
   - 三元组恢复正确；
   - 三个能量与两个相位恢复正确（容差：共轭/置换等价类内）；
2. **单图试点**：先在 10Singularities（最典型失败案例）上运行全流程，检查：
   - 三模解的暗点数是否显著多于两模解（接近实验值 10）；
   - 相关系数是否 ≥ 两模版本；
3. 试点通过后，再批量处理其余 4 图。

## 六、风险与备选

| 风险 | 应对 |
|---|---|
| 三模仍不足以表达（如 11 奇点需要 4+ 模） | 框架天然可推广到 N 模；若三模失败，输出"所需最少模式数"的证据链 |
| 粗筛漏检（降采样 + 粗网格） | 保留 top-200（宽松）；必要时加第 2 轮粗筛（不同网格相位） |
| 计算时间超预期 | 可先在模式子集（两模 top 中出现过的模式 ∪ 其邻居）上跑 |
| 解不唯一 | 结构验收作为最终仲裁；报告保留多个通过解 |

## 七、输出物与验收标准

**每图输出**：
- `<img>_three_mode.csv`：top-20 候选（三元组、3 能量、2 相位、corr、暗点数、位置距离、判定）；
- `<img>_three_mode_structural.png`：最佳解的三面板验收图；
- 与两模解的对照栏（corr 变化、暗点数变化）。

**总验收标准**：至少一解的暗点数在实验值 ±1 内、位置 < 12 px、且相关系数 ≥ 0.85；否则判定"三模仍不足"并输出证据。

**交付物**：`search_three_mode.py`（脚本）、5 图的 csv/图件、汇总报告《报告_三模搜索_五图》。
